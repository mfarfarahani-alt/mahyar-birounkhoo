افزوده‌شدن آرشیو سؤالات امتحانات نهایی
======================================

مسیر صفحه جدید:
  /final-exams

مسیر دسترسی از منوی سایت:
  ابزار کنکور > آرشیو سوالات نهایی

ساختار آرشیو:
  پایه یازدهم و پایه دوازدهم
  دسته‌بندی بر اساس درس و گروه رشته‌ای
  نمایش، جست‌وجو و دانلود مستقیم فایل‌های PDF

فایل‌های PDF در مسیر زیر قرار گرفته‌اند:
  public/files/final-exams/

فهرست فایل‌ها و اطلاعات دسته‌بندی:
  app/exam-archive/final-exams.json

فایل‌های اصلی صفحه:
  app/final-exams/page.tsx
  app/final-exams/FinalExamsClient.tsx

همچنین منوی دسکتاپ و موبایل در components/layout/Header.tsx و نقشه سایت در
app/sitemap.ts به‌روزرسانی شده‌اند.

برای اجرای پروژه:
  npm ci
  npm run build

سپس مانند روند قبلی پروژه را به مخزن GitHub و سرویس میزبانی خود ارسال کنید.

توجه: آرشیو PDF حدود 443 مگابایت حجم دارد. قبل از انتشار، سقف حجم فایل و
فضای مجاز مخزن و سرویس میزبانی را بررسی کنید. فایل‌ها در مخزن Git قرار می‌گیرند
و به سرویس خارجی یا Google Apps Script وابسته نیستند.
